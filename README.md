# RetailX AI Assistant 🤖

Este é um assistente de análise de dados inteligente desenvolvido e depois executado em um ambiente Streamlit, Google Gemini e Databricks.

## 🚀 Como executar a aplicação

1.  **Certifique-se de ter o Python instalado.**
2.  **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Execute o Streamlit:**
    ```bash
    streamlit run app.py
    ```

## 🛠️ Funcionalidades

-   **Conversão de Linguagem Natural para SQL:** Utiliza o Google Gemini para transformar perguntas em Spark SQL.
-   **Conexão Databricks:** Executa queries diretamente no ambiente Databricks da RetailX.
-   **Interpretação de Dados:** A IA analisa os resultados brutos e fornece um resumo executivo.
-   **Interface Profissional:** Sidebar customizada com as cores da RetailX e modo chat.
